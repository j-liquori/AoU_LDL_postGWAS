# AoU_LDL_postGWAS
Post-genomic analyses scripts for "Phenotypic and genetic sex differences in LDL-C and statin treatment in All of Us." Includes annotation, sex-stratified effect size comparisons, and visualization of GWAS, XWAS, and GxSex summary statistics of statin-adjusted LDL-C generated using REGENIE v2.2.4 and v3.1.4 from the All of Us Research Program (v7).

## Data Availability
The summary statistics used in this analysis are available on Zenodo:  
[https://doi.org/10.5281/zenodo.19333986](https://doi.org/10.5281/zenodo.19333986)

This repo is currently a work in progress.
